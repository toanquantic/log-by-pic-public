# LogByPic – trang công khai

Các trang công khai của ứng dụng LogByPic, phục vụ bằng GitHub Pages:

- `terms.html`: Điều khoản sử dụng / Terms of Use
- `privacy.html`: Chính sách quyền riêng tư / Privacy Policy
- `tai-app.html`: Trang tải app, có nút App Store và mã QR (`assets/qr-app-store.png`, ảnh in `assets/huong-dan-tai-app.png`). Link App Store: https://apps.apple.com/app/id6831624733

Mỗi trang có tiếng Việt ở trên và tiếng Anh ở `#en`.

URL (sau khi bật GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `/ (root)`):

- https://toanquantic.github.io/log-by-pic-public/terms.html
- https://toanquantic.github.io/log-by-pic-public/privacy.html
- https://toanquantic.github.io/log-by-pic-public/tai-app.html

Khi sửa nội dung, cập nhật ngày hiệu lực ở đầu trang. Nếu ứng dụng bắt đầu dùng thêm dữ liệu (ví dụ phân tích, báo lỗi, đồng bộ), cập nhật `privacy.html` và khai báo App Privacy / Data safety trên store trước khi phát hành.
